# Digital Clock + Date Display

A simple **Digital Clock** web application built using **HTML, CSS, and JavaScript**.  
This project displays the **current time** (hours, minutes, seconds with AM/PM) and the **current date** dynamically, updating every second.

---

## 🌟 Features

- Live digital clock that updates every second  
- 12-hour format with AM/PM  
- Current date display in the format: *Weekday, Day Month Year*  
- Responsive and modern UI with gradient background  
- Easy to customize design using CSS  

*(Optional enhancement: Dark/Light mode toggle, 24-hour format)*

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Flexbox, gradients, shadows)  
- JavaScript (DOM manipulation, setInterval, Date object)
  ## 🚀 How to Run

1. Clone or download the repository  
2. Open `index.html` in any modern web browser  
3. The clock and date will start updating automatically  

---

## 💡 How It Works

1. **JavaScript `Date` object** is used to get current time and date  
2. **setInterval()** updates the clock every 1000 milliseconds (1 second)  
3. DOM elements (`#time` and `#date`) are updated dynamically using `textContent`  
4. Hours, minutes, and seconds are formatted with leading zeros and AM/PM
